VAVEWave Tables

Send wavetables (Serum, WaveEdit, Ableton, Surge) to the 8 user slots of your FM-1. The conversion runs in this page; nothing is uploaded to a server.

Use Chrome or Edge (Safari has no Web MIDI). Plug the FM-1 in by USB with VAVEWave running.

    Notes
    
Sending takes about 5 seconds. Keys up and no sound; do not unplug the FM-1 meanwhile. If the cable is pulled or power is lost the slot simply stays empty; nothing else is touched.

    
Sending into a slot that holds a table replaces it. Use Save on that slot first to keep a copy as a .vwt file; the same file can be sent back later.

    
Only harmonics 1 to 64 of each cycle are kept (the engine's limit). A file with more than 32 frames is spread evenly over 32; with fewer, frames are blended.

    
The tables are your own files; this page and the firmware ship none.
