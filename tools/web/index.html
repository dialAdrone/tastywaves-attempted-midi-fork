TastyWaves Tables and Patches

Send wavetables (Serum, WaveEdit, Ableton, Surge) to the 8 user slots of your FM-1. The conversion runs in this page; nothing is uploaded to a server.

Install TastyWaves

Plug the FM-1 in by USB, switch it on and press Install. It takes about a minute; keep this page open and the cable in. Updating TastyWaves keeps your saved patches and wavetables; coming from another firmware, restore them from a backup. Hold OCT- while switching on for the USB rescue if anything goes wrong.

    Notes
    
Sending takes about 5 seconds. Keys up and no sound; do not unplug the FM-1 meanwhile. If the cable is pulled or power is lost the slot simply stays empty; nothing else is touched.

    
Sending into a slot that holds a table replaces it. Use Save on that slot first to keep a copy as a .vwt file; the same file can be sent back later.

    
Only harmonics 1 to 64 of each cycle are kept (the engine's limit). A file with more than 32 frames is spread evenly over 32; with fewer, frames are blended.

    
Patches: rename, reorder (the order of the PRESETS list on the FM-1), delete, back up to a JSON file and restore. A backup holds every parameter and any saved pattern of every user patch. Restoring puts each patch back under its own number and keeps the ones not in the file. A patch refers to a user table by slot number, not by content: backing up tables is the Save button on each slot.

    
The tables are your own files; this page and the firmware ship none.
